2. Preprocessing: bandpass filter, windowing/segmentation, seizure vs. non-seizure labeling

-> scripts/02_preprocess_patient.py 
---> Bandpass filter - Standard range for seizure detection work — removes slow drift and high-frequency noise/muscle artifact.
---> Window/segment - Split each recording into fixed-length windows; using 2 seconds + 0% overlap (1s stride) just for the positive/seizure regions — but keep non-overlapping windows for the negative/background regions, otherwise your negative class balloons even further and training gets slower for no benefit. 
For each window, label it seizure=1 if it overlaps a labeled seizure interval, else 0. 
Expect heavy class imbalance (seizures are rare) — note the ratio, we need it for Phase 2 (class weighting or resampling).

---> Patient-level train/test split — split by patient ID, not by window. E.g. patients 1–17 train, 18–22 test (or similar). 
Windows from the same patient in both train and test will leak information and inflate accuracy.
