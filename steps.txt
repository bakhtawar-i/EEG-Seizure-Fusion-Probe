2. Preprocessing: bandpass filter, windowing/segmentation, seizure vs. non-seizure labeling

-> scripts/02_preprocess_patient.py 
---> Bandpass filter - Standard range for seizure detection work — removes slow drift and high-frequency noise/muscle artifact.
---> Window/segment - Split each recording into fixed-length windows; using 2 seconds + 0% overlap (1s stride) just for the positive/seizure regions — but keep non-overlapping windows for the negative/background regions, otherwise your negative class balloons even further and training gets slower for no benefit. 
For each window, label it seizure=1 if it overlaps a labeled seizure interval, else 0. 
Expect heavy class imbalance (seizures are rare) — note the ratio, we need it for Phase 2 (class weighting or resampling).

---> Patient-level train/test split — split by patient ID, not by window. E.g. patients 1–17 train, 18–22 test (or similar). 
Windows from the same patient in both train and test will leak information and inflate accuracy.

-> 2. Feature Extraction
---> Raw windows are (n_windows, 18, 512) per patient; features will be (n_windows, ~120) — orders of magnitude smaller, and since we compute them per-window using a memory-mapped read (not a full load), peak memory stays flat regardless of patient size.
---> Feature set: for each window, per channel — band power (delta 0.5–4Hz, theta 4–8Hz, alpha 8–13Hz, beta 13–30Hz, gamma 30–40Hz) via Welch's method, plus variance and line length (both cheap, standard time-domain features in seizure detection literature). 
---> That's 5 band powers + 2 time-domain features × 18 channels = 126 features per window.

AUC-ROC: 0.8696
AUC-PR: 0.1501
Sensitivity (recall): 0.3090
Precision: 0.0698
False alarms/hour: 38.07
Confusion matrix: TN=163728, FP=3556, FN=597, TP=267

---> What's working: AUC-ROC of 0.87 says the model can rank seizure windows above non-seizure windows reasonably well overall, the features (band power, variance, line length) are capturing real signal.

---> What's not working, and why it matters more here: AUC-PR of 0.15 and sensitivity of 0.31 are the real story given this task. 
Only catching 31% of actual seizure windows — missing roughly 2 out of every 3. 
And 38 false alarms per hour is clinically unusable — for context, published CHB-MIT seizure detection work typically targets single-digit false alarms per hour; 38/hr means the model flags something almost every 90 seconds, which no clinician would tolerate.

---> Why the gap between AUC-ROC and AUC-PR is so large: this is exactly what severe class imbalance does — ROC-AUC is measuring against a huge pool of true negatives, so it looks good almost by default, 
while AUC-PR (which only cares about positive-class performance) exposes that the model is still struggling with the actual seizure-detection task.

def get_metrics(output, target, metrics, is_binary, threshold=0.5):
    """
    Drop-in replacement for pyhealth.metrics.binary_metrics_fn /
    multiclass_metrics_fn, using scikit-learn instead — avoids a
    pandas<2 dependency conflict from pyhealth.
    """
    import numpy as np
    from sklearn.metrics import (
        accuracy_score, balanced_accuracy_score, roc_auc_score,
        average_precision_score, f1_score, precision_score, recall_score,
        cohen_kappa_score
    )

    output = np.asarray(output)
    target = np.asarray(target)

    if is_binary:
        if 'roc_auc' not in metrics or sum(target) * (len(target) - sum(target)) != 0:
            preds = (output >= threshold).astype(int)
            results = {}
            for m in metrics:
                if m == "accuracy":
                    results[m] = accuracy_score(target, preds)
                elif m == "balanced_accuracy":
                    results[m] = balanced_accuracy_score(target, preds)
                elif m == "pr_auc":
                    results[m] = average_precision_score(target, output)
                elif m == "roc_auc":
                    results[m] = roc_auc_score(target, output)
                elif m == "f1":
                    results[m] = f1_score(target, preds)
                elif m == "precision":
                    results[m] = precision_score(target, preds, zero_division=0)
                elif m == "recall":
                    results[m] = recall_score(target, preds)
                else:
                    raise ValueError(f"Unsupported metric: {m}")
        else:
            results = {
                "accuracy": 0.0,
                "balanced_accuracy": 0.0,
                "pr_auc": 0.0,
                "roc_auc": 0.0,
            }
    else:
        preds = np.argmax(output, axis=1)
        results = {}
        for m in metrics:
            if m == "accuracy":
                results[m] = accuracy_score(target, preds)
            elif m == "balanced_accuracy":
                results[m] = balanced_accuracy_score(target, preds)
            elif m == "f1_weighted":
                results[m] = f1_score(target, preds, average="weighted")
            elif m == "cohen_kappa":
                results[m] = cohen_kappa_score(target, preds)
            else:
                raise ValueError(f"Unsupported metric: {m}")
    return results
